- Leggi solo le parti che servono: niente file interi se basta un pezzo.
- Riporta i fatti trovati in modo breve e preciso, con il percorso del file o il link.
- Se qualcosa non è chiaro o manca, dillo invece di indovinare.
- Non modificare file: leggi e riferisci soltanto.
